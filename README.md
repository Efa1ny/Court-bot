# Court bot

Discord-бот для судебной системы GTA 5 RP. Формирует BB-код документов Верховного
и Федерального судов, отслеживает новые исковые темы на форуме и работает с
кадровыми, штрафными и выплатными листами Google Таблицы.

## Возможности

- `/создать документ` — выбор шаблона и заполнение реквизитов. В том числе доступны
  принятие и отказ в принятии иска, решения, определения, ордера ASC/IA и
  документы о юридической реабилитации. Список берётся из `templates/manifest.json`.
- `/создать подпись` — HTTPS-ссылка на изображение подписи или текстовая подпись
  в формате «И.Фамилия».
- `/история` — список своих документов; `/история номер_документа:<ID>` —
  повторное скачивание документа.
- `/таблица штраф`, `/таблица выплата`, `/таблица оплата`, `/таблица казна`,
  `/таблица ордер`, `/таблица отмена`, `/таблица премии` — работа со штрафами,
  выплатами и премиями.
- `/статистика` — статистика рассмотрения исков и реабилитации;
  `/сводка` — отправка сводки по делам и финансам в канал мониторинга.
- `/рестарт шаблонов` и `/рестарт бота` — команды администратора.

При включении мониторинг проверяет форум каждые пять минут. О новой теме ответственным судьям
отправляется одно упоминание; уже существующие темы не пингуются при первой
индексации. В полночь по московскому времени бот публикует сводку. Удалённые с
форума темы исключаются после полного сканирования.

## Подготовка

Нужны Python 3.11 или 3.12, Discord-приложение с установленным ботом и доступ
к нужному серверу. Для команд используйте scopes `applications.commands` и `bot`;
боту необходимы права читать канал, отправлять сообщения, прикреплять файлы и
встраивать ссылки. Привилегированные intents не требуются.

Создайте виртуальное окружение, установите зависимости и скопируйте пример
настроек:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

В Windows PowerShell используйте `py -3.12 -m venv .venv`,
`.\.venv\Scripts\Activate.ps1` и `Copy-Item .env.example .env`.
Заполните `.env` с переменными из таблицы ниже, затем запустите `python run.py`.
Файл `.env` не должен попадать в Git. Если токен раскрыт, немедленно
перевыпустите его в Discord Developer Portal.

### Основные переменные `.env`

| Переменная | Назначение |
| --- | --- |
| `DISCORD_TOKEN` | Токен бота; обязателен. |
| `TEST_GUILD_ID` | Необязательный ID тестового сервера для быстрой синхронизации команд. |
| `ALLOWED_ROLE_IDS` | ID ролей, которым разрешены команды; администраторы сервера тоже имеют доступ. |
| `TEMPLATES_DIR`, `DATABASE_PATH` | Пути к BB-шаблонам и SQLite; по умолчанию `templates` и `data/court_bot.db`. |
| `FORUM_MONITOR_ENABLED` | `1` включает фоновый мониторинг; по умолчанию он выключен. |
| `FORUM_ALERT_CHANNEL_ID` | Канал уведомлений и сводки; обязателен при включённом мониторинге. |
| `ROLE_SUPREME_CHAIR_ID`, `ROLE_SUPREME_JUDGE_ID`, `ROLE_FEDERAL_CHAIR_ID`, `ROLE_FEDERAL_JUDGE_ID`, `ROLE_JUDICIAL_CORPS_ID` | Роли для уведомлений; обязательны при включённом мониторинге. |
| `GOOGLE_SHEETS_ID` | ID вашей Google Таблицы; в коде нет предустановленного ID. |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | Путь к JSON-ключу сервисного аккаунта или его содержимое. |

Для создания документов и работы с таблицей Discord-пользователь должен
присутствовать в кадровом листе Google Таблицы:
оттуда берутся его имя и должность. Сервисному аккаунту нужен доступ к таблице.
Его JSON-ключ храните вне репозитория, например в `data/` на сервере.

## Шаблоны документов

BB-шаблоны находятся в `templates/`, их перечень — в `templates/manifest.json`.
Общие подстановки включают `{{claim_number}}`, `{{respondent_name}}`,
`{{document_date}}`, `{{author_full_name}}` и `{{author_signature}}`. Для принятия
иска доступны административное и уголовное судопроизводство; процессуальные
статусы автоматически вставляются в нужном падеже. Изменение текста существующего
шаблона можно применить через `/рестарт шаблонов`. Новые поля или формы требуют
изменения кода и перезапуска бота.

## Проверки

```bash
python -m pip install -r requirements-dev.txt
python -W error::ResourceWarning -m unittest discover -s tests -v
ruff check courtbot tests run.py
python -m compileall -q courtbot run.py
```

## Размещение

Для нового Docker-развёртывания предусмотрены `Dockerfile` и `compose.yaml`.
Создайте `.env` на сервере и выполните `docker compose up -d --build`; состояние
SQLite хранится в volume `court_bot_data`. Просмотр журналов —
`docker compose logs -f`.

При размещении без Docker можно настроить службу systemd на своём сервере.
Храните рабочие `.env`, базу данных и виртуальное окружение на сервере отдельно
от публикуемого кода. Перед обновлением сохраните резервную копию и проверьте,
что все ID канала, ролей и Google Таблицы указаны в серверном `.env`.

## Безопасность

`.env`, JSON-ключ сервисного аккаунта, база SQLite и виртуальные окружения не
должны публиковаться. Не добавляйте их в Git принудительно. При обнаружении
уязвимости следуйте [политике безопасности](SECURITY.md).
