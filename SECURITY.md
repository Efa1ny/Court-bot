# Политика безопасности

## Поддерживаемая версия

Исправления безопасности вносятся в актуальный код ветки `main`. Старые архивы
и отдельные копии проекта не поддерживаются.

## Сообщить об уязвимости

Не публикуйте уязвимость, токен или ключ в открытом issue, обсуждении либо
логах. Используйте приватное сообщение о безопасности через раздел
**Security → Advisories** репозитория, если он доступен; иначе свяжитесь с
владельцем репозитория приватно. Укажите затронутый компонент, шаги
воспроизведения, возможные последствия и способ исправления. Не прикладывайте
действующие секреты.

Если раскрыт Discord-токен или ключ сервисного аккаунта Google, сразу отзовите
его, выпустите новый и проверьте доступ к соответствующим ресурсам. Удаление
секрета из последнего коммита не удаляет его из истории Git.

## Развёртывание и доступ

- Храните `.env`, JSON-ключ Google и SQLite-базу вне Git и архивов публикации.
  Для секретных файлов ограничьте права доступа на сервере.
- Выдавайте сервисному аккаунту доступ только к необходимой Google Таблице;
  для Discord-бота используйте минимально достаточные права в каналах.
- Команды бота ограничены разрешёнными ролями или правом Administrator.
  Создание документов и операции с таблицей дополнительно сверяют пользователя
  с кадровым листом. История документов выдаётся только их автору.
- Административные команды перезапуска доступны только пользователям с правом
  Administrator на сервере Discord.
- Обновляйте зависимости и проверяйте их уязвимости при развёртывании.
